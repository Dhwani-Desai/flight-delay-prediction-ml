# Flight Delay Prediction Using Machine Learning & Explainable AI

## Project Overview

This project aims to predict flight arrival delays using
historical flight data and supervised machine learning
techniques.

The project explores data preprocessing, feature
engineering, model comparison, hyperparameter tuning
and Explainable AI to identify factors associated with
flight delays.

## Research Question

How accurately can machine learning models predict
flight delays before departure, and which features
contribute most to these predictions?

## Project Objectives

- Analyse historical flight data.
- Clean and preprocess real-world datasets.
- Build and compare machine learning models.
- Optimise model performance.
- Interpret predictions using Explainable AI.
- Document experimental findings and limitations.
